    Estruturas de Seleção: Conceito Básico

    As estruturas de seleção são uma das principais estruturas de controle utilizadas em programação. Elas permitem que o programa execute diferentes blocos de código com base em condições específicas.

    Estruturas de Seleção: Switch Case e If-Elif-Else

    Existem duas estruturas de seleção principais: Switch Case e If-Elif-Else.

    • Switch Case: Utilizado para avaliar o valor de uma única variável e executar um bloco de código específico com base nessa avaliação. É mais eficiente quando há muitos casos diferentes a serem avaliados.
    • If-Elif-Else: Utilizado para avaliar várias condições e executar um bloco de código específico com base nessas condições. É mais flexível e utilizado quando as condições de decisão são mais complexas.

    Sintaxe Geral de Estruturas de Seleção

    A sintaxe geral das estruturas de seleção é a seguinte:

    • Switch Case:
      • if (variável == valor1) { // bloco de código 1 } else if (variável == valor2) { // bloco de código 2 } else { // bloco de código default }
    • If-Elif-Else:
      • if (condição1) { // bloco de código 1 } else if (condição2) { // bloco de código 2 } else { // bloco de código default }

# 📚 Aula 1: O que é programar?

## 🎯 Objetivos de Aprendizagem
- Compreender o conceito de algoritmos
- Conhecer o uso da lógica de programação
- Desenvolver sistemas computacionais utilizando ambiente de desenvolvimento

## ⏱️ Cronograma da Aula

| Tempo | Atividade | Descrição |
|-------|-----------|-----------|
| 0-10min | Introdução | Apresentação do tema e motivação para aprender |
| 10-25min | Conteúdo Principal | Desenvolvimento do conceito de algoritmos e lógica de programação |
| 25-40min | Atividade Prática | Criação de um algoritmo para trocar uma lâmpada |
| 40-50min | Fechamento | Resumo e próximos passos |

## 📖 Conteúdo da Aula

### 1️⃣ Introdução (10 min)
🎉 **Bem-vindos!** Hoje vamos explorar o mundo da programação e entender o que é um algoritmo. 🤔

💬 **DISCUSSÃO EM CLASSE**: O que vocês já sabem sobre programação? 🤔

### 2️⃣ Desenvolvimento (30 min)
#### Conceito Chave: Algoritmo
Um algoritmo é uma sequência de passos lógicos para resolver um problema. 📊

📊 **EXEMPLO PRÁTICO**: Vamos criar um algoritmo para trocar uma lâmpada! 🎉

🤔 **PAUSA PARA REFLEXÃO**: Por que a lógica é importante em programação? 🤔

### 3️⃣ Atividade Prática (15 min)
🎉 **CRIEM UM ALGORITMO!** Vamos criar um algoritmo para trocar uma lâmpada! 🎉

### 4️⃣ Fechamento (5 min)
👍 **RESUMO!** Vamos resumir o que aprendemos hoje! 📚

## 💡 Pontos-Chave para Memorizar
- ✅ Um algoritmo é uma sequência de passos lógicos
- ✅ A lógica é importante em programação
- ✅ Algoritmos podem ser aplicados em diversas áreas

## 🏠 Tarefa para Casa
🎉 **CRIE UM ALGORITMO!** Vamos criar um algoritmo para resolver um problema do seu dia a dia! 🎉

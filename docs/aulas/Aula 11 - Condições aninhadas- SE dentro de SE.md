### 📋 Tópicos Principais

#### 1. Introdução ao conceito de condições aninhadas

**O que são condições aninhadas?**

Condições aninhadas são uma forma de estrutura de decisão que permite que o programa tome decisões baseadas em condições múltiplas. Elas são criadas combinando condições if-else dentro de outras condições if-else.

**Exemplo:**

```python
if idade >= 18:
    if sexo == 'M':
        print("Homem maior de 18 anos")
    else:
        print("Mulher maior de 18 anos")
else:
    print("Menor de 18 anos")
```

#### 2. Exemplos práticos de condições aninhadas

**Exemplo 1:**

```python
nota = float(input("Digite a nota: "))

if nota >= 7:
    if sexo == 'M':
        print("Parabéns! Homem aprovado")
    else:
        print("Parabéns! Mulher aprovada")
else:
    print("Infelizmente, não foi aprovado")
```

#### 3. Utilização de condições aninhadas em programas

**Exemplo:**

```python
idade = int(input("Digite a idade: "))
sexo = input("Digite o sexo (M/F): ")

if idade >= 18:
    if sexo == 'M':
        print("Homem maior de 18 anos")
    else:
        print("Mulher maior de 18 anos")
else:
    print("Menor de 18 anos")
```

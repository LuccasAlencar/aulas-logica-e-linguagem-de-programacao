### Introdução à estrutura de decisão composta
-----------------------------------------------

🎯 Objetivo: Compreender a estrutura de decisão composta e sua importância em programação

📝 Conteúdo:

A estrutura de decisão composta é uma estrutura de controle de fluxo que permite que o programa execute diferentes blocos de código com base em condições específicas. Ela é utilizada para tratar casos mais complexos, onde não basta apenas verificar uma condição, mas sim combinar várias condições para tomar uma decisão.

A estrutura composta é composta por `if`, `elif` e `else`, que trabalham juntos para criar uma cadeia de condições. O `if` é usado para verificar a primeira condição, o `elif` é usado para verificar condições adicionais e o `else` é usado para executar o código quando todas as condições forem falsas.

### Entendimento do uso de múltiplos elif na mesma estrutura de decisão
--------------------------------------------------------------------------------

🎯 Objetivo: Compreender como utilizar múltiplos `elif` na estrutura de decisão composta

📝 Conteúdo:

A estrutura de decisão composta pode ter múltiplos `elif` para verificar condições adicionais. Cada `elif` é usado para verificar uma condição específica e executar o código correspondente.

Exemplo:

```python
x = 5
if x > 10:
    print("x é maior que 10")
elif x == 5:
    print("x é igual a 5")
else:
    print("x é menor que 10")
```

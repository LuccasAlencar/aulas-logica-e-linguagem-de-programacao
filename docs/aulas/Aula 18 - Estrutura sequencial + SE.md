**Abertura e Introdução (0-10min)**

Bem-vindos, alunos! Hoje vamos explorar a estrutura sequencial + SE, um conceito fundamental na programação. A estrutura sequencial é uma das estruturas de controle mais básicas e é usada para especificar a ordem em que as instruções de um algoritmo são executadas.

A estrutura sequencial + SE é uma extensão da estrutura sequencial, que inclui a possibilidade de realizar operações condicionais, como verificar se uma condição é verdadeira ou falsa. Isso permite que os algoritmos sejam mais flexíveis e capazes de lidar com situações mais complexas.

**Exposição e Desenvolvimento (10-20min)**

A estrutura sequencial + SE é composta por uma sequência de instruções que são executadas em ordem, seguidas de uma estrutura de decisão que verifica se uma condição é verdadeira ou falsa. Se a condição for verdadeira, as instruções dentro da estrutura de decisão são executadas. Se a condição for falsa, as instruções dentro da estrutura de decisão são puladas.

A estrutura sequencial + SE é usada em muitos contextos, incluindo a programação de computadores, a automação industrial e a robótica. Ela é essencial para a construção de algoritmos que podem lidar com situações complexas e variáveis.

**Atividade de Laboratório (20-35min)**

Agora, vamos praticar a estrutura sequencial + SE com um exemplo prático. Vamos criar um programa que verifique se uma pessoa pode doar sangue ou não.

**Exemplo:**

*   Uma pessoa pode doar sangue se:
    *   tem entre 16 e 69 anos;
    *   pesa 50 kg ou mais;
    *   não está grávida;
    *   não doou sangue nos últimos 90 dias.

**Código:**

```python
idade = 30
peso = 55
gravida = False
doou_90_dias = False

if 16 <= idade <= 69 and peso >= 50 and not gravida and not doou_90_dias:
    print("Você está apto para doar sangue!")
else:
    print("Infelizmente, você não está apto para doar sangue.")
```

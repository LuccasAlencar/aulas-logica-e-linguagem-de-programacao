# 📚 Aula 4: Variáveis e Tipos de Dados

## 🎯 Objetivos de Aprendizagem

- Conhecer os princípios da criação de algoritmos em lógica de programação, utilizando conceitos variáveis e fluxos de dados.
- Desenvolver sistemas computacionais utilizando ambiente de desenvolvimento.
- Trabalhar o uso da lógica na resolução de problemas computacionais.

## ⏱️ Cronograma da Aula

| Tempo | Atividade | Descrição |
|-------|-----------|-----------|
| 0-10min | Introdução | Apresentação dos objetivos da aula e contextualização do tema. |
| 10-25min | Conteúdo Principal | Explicação dos conceitos de algoritmos, incluindo entradas, saídas, efetividade, finitude e precisão. |
| 25-40min | Exemplos de Algoritmos | Análise de exemplos práticos de algoritmos em diferentes contextos, como receita de bolo e instruções para montar um móvel. |
| 40-55min | Desligar o Computador | Desenvolvimento de um fluxograma para desligar o computador. |
| 55-70min | Atividade Prática | Construção de um fluxograma básico para a simulação de financiamentos em um aplicativo. |
| 70-85min | Fechamento | Resumo dos principais conceitos e discussão em classe sobre a importância da lógica em programação. |

## 📖 Conteúdo da Aula

### 1️⃣ Introdução (10 min)

👋 **Bem-Vindo à Aula!**: Hoje vamos explorar os fundamentos da lógica de programação, aprendendo a criar algoritmos eficientes e eficazes.

💬 **DISCUSSÃO EM CLASSE**: O que é um algoritmo? Por que é importante entender como funcionam?

### 2️⃣ Desenvolvimento (30 min)

#### Conceito Chave: Algoritmos

Um algoritmo é uma sequência de instruções que são executadas em um determinado orden para resolver um problema específico.

📊 **EXEMPLO PRÁTICO**: Imagine você precisando fazer uma receita de bolo. Cada passo da receita é um algoritmo que precisa ser executado em ordem para obter o resultado desejado.

🤔 **PAUSA PARA REFLEXÃO**: Quais são os principais componentes de um algoritmo?

### 3️⃣ Atividade Prática (15 min)

📊 **CONSTRUA UM FLUXOGRAMA**: Desenvolva um fluxograma básico para desligar o computador.

### 4️⃣ Fechamento (5 min)

👋 **RESUMO DA AULA**: Recapitulemos os principais conceitos aprendidos hoje.

## 💡 Pontos-Chave para Memorizar

- **Entradas e Saídas**: Algoritmos têm entradas (valores fornecidos) e saídas (valores produzidos).
- **Efetividade**: Cada passo do algoritmo deve ser suficientemente básico para ser realizado em princípio, exatamente e em tempo finito.
- **Finitude**: Algoritmos devem terminar após um número finito de passos.

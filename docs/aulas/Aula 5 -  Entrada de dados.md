### Exposição - Introdução às Estruturas de Decisão Simples (0-10min)

As estruturas de decisão são fundamentais para a programação, pois permitem ao desenvolvedor criar algoritmos que tomam decisões com base em condições específicas. Isso é essencial para criar programas eficazes e robustos. Vamos explorar os conceitos básicos das estruturas de decisão simples e como elas são utilizadas em algoritmos.

### Desenvolvimento da Aula - Conceitos de Algoritmos (10-20min)

Um algoritmo é uma sequência de instruções que podem ser executadas por um computador para resolver um problema. Os algoritmos podem ser classificados em três tipos principais: sequência, seleção e repetição.

*   Sequência: é a execução linear de instruções em ordem específica.
*   Seleção: permite que o algoritmo faça escolhas com base em condições específicas.
*   Repetição: executa um bloco de código várias vezes até que uma condição específica seja atendida.

### Desenvolvimento da Aula - Estruturas de Decisão (20-30min)

As estruturas de decisão são utilizadas para tomar decisões com base em condições específicas. As estruturas de decisão mais comuns são:

*   Estrutura de decisão condicional: é utilizada para tomar decisões com base em condições específicas.
*   Estrutura de decisão de seleção múltipla: é utilizada para tomar decisões com base em várias condições.

### Atividade - Montagem do Fluxo de Pagamento (30-40min)

Vamos criar um fluxo de pagamento de loja de departamentos utilizando estruturas de decisão simples. O fluxo deve considerar que o pagamento pode ser feito em cartão ou dinheiro.

**Exemplo de Fluxo de Pagamento:**

1.  Início
2.  Ler o tipo de pagamento (cartão ou dinheiro)
3.  Se o tipo de pagamento for cartão:
    1.  Ler o número do cartão
    2.  Ler a data de validade do cartão
    3.  Ler o código de segurança do cartão
4.  Se o tipo de pagamento for dinheiro:
    1.  Ler a quantidade de dinheiro
5.  Processar o pagamento
6.  Imprimir o recibo

### Discussão e Feedback (40-50min)

Vamos discutir o fluxo de pagamento criado e receber feedback sobre como ele pode ser melhorado. Isso ajudará a identificar áreas de melhoria e a refinir o fluxo.

**Exemplo de Discussão:**

*   Qual foi o maior desafio ao criar o fluxo de pagamento?
*   Como podemos melhorar o fluxo de pagamento?
*   Quais são as implicações das estruturas de decisão simples no fluxo de pagamento?

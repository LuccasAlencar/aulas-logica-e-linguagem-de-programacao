**Introdução**

Bem-vindos à aula sobre estruturas de seleção! Hoje vamos explorar como o Python pode ser utilizado para resolver problemas complexos utilizando estruturas de seleção. Vamos começar com uma breve introdução sobre a história do Python e como ele se tornou uma das linguagens de programação mais populares do mundo.

**Exposição**

A linguagem Python foi criada em 1989 por Guido Van Rossum. Ele foi inspirado pela linguagem ABC e começou a desenvolver o Python como uma linguagem de script. O objetivo era criar uma linguagem que fosse fácil de aprender e utilizar, com uma sintaxe simples e legível.

Aqui está a linha do tempo da história do Python:

* 1982: Guido Van Rossum trabalha no CWI em Amsterdã
* 1987: Guido é transferido para o grupo de trabalho Amoeba
* 1989: O desenvolvimento do Python começa
* 1990: A primeira versão do Python é lançada
* 1991: O Python se torna uma linguagem de programação popular

**Exemplo de Código**

Vamos criar um exemplo simples de código que utiliza estruturas de seleção. Suponha que você esteja trabalhando em um sistema de gestão de estoque e precisa calcular o desconto para um cliente. O código abaixo mostra como isso pode ser feito utilizando o Python:

```python
valor_da_compra = 150 # Valor em reais
cliente_fidelidade = True
if valor_da_compra > 100:
    if cliente_fidelidade:
        print("Você ganhou 20% de desconto e frete grátis!")
    else:
        print("Você ganhou 10% de desconto.")
else:
    print("Aproveite nossas ofertas e aumente sua compra para ganhar desconto!")
```

**Atividade: Montagem do Fluxo de Pagamento**

Agora é sua vez! Vamos criar um fluxo de pagamento utilizando o Python. Suponha que você esteja trabalhando em um sistema de pagamento online e precisa criar um fluxo que processe as informações do cliente e gere o pagamento.

```python
# Informações do cliente
nome = input("Digite o nome do cliente: ")
email = input("Digite o e-mail do cliente: ")

# Informações do pagamento
valor = float(input("Digite o valor do pagamento: "))
forma_pagamento = input("Digite a forma de pagamento: ")

# Processamento do pagamento
if valor > 100:
    print("O pagamento foi realizado com sucesso!")
else:
    print("O pagamento não foi realizado.")

# Geração do recibo
print("Recibo de pagamento:")
print("Nome:", nome)
print("E-mail:", email)
print("Valor:", valor)
print("Forma de pagamento:", forma_pagamento)
```

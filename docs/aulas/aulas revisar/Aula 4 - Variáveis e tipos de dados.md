### Exposição

#### Definição de Algoritmo

Um algoritmo é uma sequência de passos que descreve como resolver um problema ou realizar uma tarefa. Ele é composto por uma entrada, um processo e uma saída.

- **Entrada**: valores fornecidos antes do início do processo.
- **Processo**: os passos necessários para resolver o problema ou realizar a tarefa.
- **Saída**: os resultados produzidos após o término do processo.

#### Características Principais de um Algoritmo

- **Efetividade**: cada passo deve ser suficientemente básico para ser realizado em princípio, exatamente e em tempo finito.
- **Finitude**: o algoritmo deve terminar após um número finito de passos.
- **Precisão**: cada passo deve ser precisamente definido.

### Exemplos de Algoritmos

- **Receita de Bolo**: saída (bolo assado), entrada (ingredientes), processo (misturar ingredientes, assar etc.).
- **Montar um Móvel**: saída (móvel montado), entrada (peças do móvel, ferramentas), processo (conectar peças conforme indicado).

### Desligar o Computador

1. Início do algoritmo.
2. Salvar todos os arquivos e fechar os programas abertos.
3. Verificar se há algum download ou processo em andamento e pausá-los.
4. Clicar no menu Iniciar.
5. Selecionar a opção “Desligar”.
6. Aguardar o processo de desligamento do computador.
7. Certificar-se de que todos os dispositivos conectados ao computador estão desligados.
8. Desligar o monitor, se necessário.
9. Verificar se todos os cabos de energia estão devidamente desconectados, se aplicável.
10. Fim do algoritmo.

### Introdução ao Conceito de Fluxogramas

Um fluxograma é uma representação visual de um algoritmo, mostrando os passos necessários para resolver um problema ou realizar uma tarefa.

### Atividade: Construção de um Fluxograma Básico

- **Objetivo**: Aplicar os primeiros conceitos de fluxogramas voltados para o passo a passo lógico de um algoritmo.
- **Tarefa**: Desenhar um fluxograma básico para o algoritmo de desligar o computador.
